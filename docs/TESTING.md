# Проверка игровой логики

Команда:

```sh
node --test tests/*.test.mjs
```

Проверки охватывают:

- изометрические координаты, равную скорость направлений и столкновения;
- урон, ресурсы, перекат, парирование, скольжение и тяжёлые атаки;
- характеристики, три слота, повреждённые сохранения и возрождение;
- взаимодействия, проходимость регионов и условия концовок;
- исцеление Амелии, теневые атаки Мерго и появление спасённого персонажа;
- обход препятствий и недостижимые цели.

Текущий результат: **36/36**.

Дополнительный прогон симуляции:

```sh
node tests/bot-playtest.mjs
```

Он записывает локальные отчёты `docs/BOT-PLAYTEST.md` и `docs/bot-playtest.json`; эти результаты исключены из Git. Такой прогон проверяет логику, но не заменяет ручное прохождение, оценку сложности и визуальную проверку.

В браузере ранее проверены меню, выбор слота, запуск, продолжение сохранения, фонарь и переход в Сон охотника. Полное ручное прохождение и физический телефон пока не проверены.
